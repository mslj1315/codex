# 餐饮内容平台项目交接

更新日期：2026-08-16

## 当前线上入口

- 统一内部管理后台：`https://app.msljkj.cn/admin/`
- Android Cloud Test APK：`https://app.msljkj.cn/downloads/restaurant-operations-cloud-test.apk`
- 服务健康检查：`https://app.msljkj.cn/health`
- 旧 `/provider/` 与 `/operator/` 入口会 302 跳转到 `/admin/`；旧静态资源不再发布。

## 已交付能力

- 客户内容档案、首访门禁、内容任务、三版差异化文案、确定性规则与 AI 语义审核、确认锁和确认后分镜生成。
- Android 客户端内容创作、分镜轻量剪辑、客户媒体上传、服务端渲染队列与受保护下载流程。
- 统一中文内部后台 `/admin/`：权限管理、内部账号与角色、客户账号开通/重置/停用、模型配置与客户分配、模型计价、运营模板和审核规则版本管理。
- 内部角色不会获得客户资源主体。即使超级管理员也不能读取客户灵感、文案正文、审核记录、分镜、原始媒体或对象地址。
- 模型 API 密钥只在服务端使用；受管模型密钥采用 AES-256-GCM 加密保存，后台读取接口不回显密钥或密文。
- 客户账号支持手机号标准化、随机一次性临时密码、强制首次改密、会话撤销与旧 scrypt 密码兼容升级。
- 新设置密码规则：至少 8 个 Unicode 字符，至少含一个 ASCII 大写和一个 ASCII 小写字母；不要求数字或符号；bcrypt 上限为 72 个 UTF-8 字节。
- Android `cloudTest` 使用正式 HTTPS API 地址，可与未来正式包并存安装。

## 线上部署状态

- 服务器：`47.108.253.48`，域名 `app.msljkj.cn`。
- 当前 API 镜像：`restaurant-ops-api:20260816-password-policy`。
- API 仅绑定服务器本机 `127.0.0.1:3000`，由 Nginx 提供 HTTPS 反向代理。
- PostgreSQL 不公开暴露端口。
- APK 使用精确下载路径，不开放目录浏览，并返回 Android APK MIME 类型和附件下载头。
- 视频存储生产开关仍为 `VIDEO_STORAGE_MODE=disabled`；未配置完成前不得启用上传、渲染或对象存储。
- 每次部署前应保留 PostgreSQL 备份。最近一次切换密码规则镜像前已在服务器 `/root/` 创建带时间戳的 SQL 备份。

## 账号与操作边界

- 内部管理员账号只能登录 `/admin/`；不能登录客户 Android 客户端。
- Android 客户端只供客户账号使用。后台创建客户后返回一次随机临时密码；客户首次登录必须改密。
- 现有客户开通 UI 仍要求填写内部企业 ID 与门店 ID，且临时密码仅在创建/重置成功时显示一次。后续应改造成由运营人员填写企业名称和门店名称、系统生成并隐藏内部 ID、提供明确的临时密码复制交接与客户列表状态流程。
- 客户忘记临时密码或密码时，应使用后台“重置密码”生成新的临时密码，不应尝试找回旧密码。

## 模型配置与计费

- 统一后台可以维护服务端模型配置、启用状态、默认模型、客户覆盖分配以及输入/输出 token 单价。
- 成功生成时冻结命中价格版本和成本快照；客户只看本月聚合用量/成本，内部后台看安全聚合计费数据。
- 服务端生产环境必须保留稳定的 `MODEL_CONFIG_ENCRYPTION_KEY`。该值仅在服务器 `.env` 中，不能提交、不能写入 Android、浏览器、Nginx 或日志。
- 当前官方抖音数据回调属于二期，不应接入订单明细、消费者隐私、POS 或自动发布；客户仍手动发布抖音作品。
