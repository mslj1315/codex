# Restaurant Video Content Planning Design

## Goal

为餐饮门店建立一个以真实经营事实为基础的抖音内容策划闭环：门店先完成经营画像，客户可以记录灵感，也可以在没有灵感时让系统根据已确认经营数据和平台自有结构化模板主动出题；客户选择题材、选择文案、修改并确认后，系统生成逐镜头拍摄清单。发布后的抖音数据通过客户导出的单任务 CSV/XLSX 报表回流，用于内容表现、商品转化、经营目标和低复杂度实验复盘。

本期只完成内容策划、审核、分镜和数据复盘基础，不实现视频素材上传、自动剪辑、字幕、转场、渲染、视频通知或抖音自动发布。

## Product Boundaries

- 第一阶段只支持抖音内容规划，不自动发布到抖音。
- 第三方爆款参考只保存客户粘贴的链接、平台和备注；不自动抓取正文、视频、评论或素材。
- 平台自有爆品文案库只保存结构化模板，不复制第三方完整爆文。
- AI 只用于题材、文案、语义审核辅助和分镜生成；确定性规则、数据解析和效果计算不依赖 AI。
- Android 不接触模型密钥、抖音凭据或对象存储凭据。
- 未确认文案和审核风险内容只对客户本人可见；服务商只能看到负责门店的已确认最终文案和聚合效果。
- 平台内部授权的 AI 训练/效果分析人员可以在平台内查看确认后的完整文案，但禁止批量导出原文。
- 客户界面不显示训练授权开关；确认后的内容按平台统一规则进入效果分析和平台 AI 改进流程。

## First-Visit Store Profile

首次建店只创建一个门店。以下字段必填，完成后即可进入工作台：

- 门店名称。
- 一级业态：快餐/简餐、正餐、火锅/串串、烧烤/夜宵、饮品/甜品、烘焙、小吃/地方特色或其他。
- 预设具体品类，以及可选的自定义品类补充。
- 省、市、区/县级联选择。
- 客户手动填写详细门店地址。
- 预设商圈类型：写字楼、社区、商场、学校、景区、交通枢纽、工业园区、住宅与商业混合、餐饮街/夜市或其他；其他允许补充说明。
- 经营模式：到店、外卖、到店+外卖、团购/套餐或多种模式并行。

不阻塞首次进入的建议字段包括面积、座位数、营业时间、外卖/团购能力、主要客群、人均消费和开业时长。画像完整度需要显示，缺少建议字段时降低推荐置信度但不阻止使用。

地址只用于门店识别、经营画像和场景判断；本期不接地图 API、不自动识别商圈、不采集顾客地址、定位或轨迹。门店画像的修改记录生效时间，历史内容任务保存生成时的画像快照。

## Operating Goals

门店在每个经营阶段选择一个主目标和一个可选辅助目标。目标可以手动切换，修改必须填写生效日期；新目标只影响生效后的内容，历史任务保存目标快照。

可选目标包括拉新获客、提升到店、推广单品、推广套餐、提升客单价、提升复购、提升外卖订单、提升团购核销、提升品牌认知和暂未确定。内容任务默认继承当前阶段目标，也可以为单条内容覆盖目标。

同一天只能有一个生效阶段，历史阶段不能被新目标重解释。系统可以提示目标与数据不匹配，但不能自动切换客户目标。

## Content Inputs

每个内容任务可以组合以下输入：

1. 客户灵感，优先决定故事核心；没有灵感时可以为空。
2. 已确认经营数据，用于选择适合带出的商品、套餐和经营目标，不得把未确认数据当成事实。
3. 平台运营后台发布的结构化文案模板。
4. 人设、内容类型、商业强度和表达风格固定预设。
5. 可选的第三方参考链接、平台和客户备注；仅作结构参考。

人设包括老板真诚分享、厨师专业讲解、店员日常记录、顾客体验视角、门店探店视角和后厨制作视角。内容类型包括门店故事、顾客故事、厨艺/食材知识、员工日常、地方生活/场景、情绪共鸣、轻松搞笑、新品介绍、菜品体验、套餐推荐和到店活动。

商业强度分为：0 纯内容、1 轻度带出、2 明确推荐、3 直接转化。默认使用 1，不应把每条内容生成成广告。风格由真诚、轻松、温暖、搞笑、专业、生活化、反差、有烟火气、快节奏和叙事感等固定预设组成。

## Template Library

平台运营后台维护自有结构化模板，服务商不能管理模板。模板模块包括开头钩子、故事推进、情绪/价值点、商品出现方式、行动引导、镜头节奏、字幕/口播要求、禁用表达和谨慎表达。

模板拥有业态、品类、人设、内容类型、商业强度、风格、价格/优惠/效果承诺限制、版本和风险等级。只有已发布版本参与生成；修改产生新版本，历史内容保留实际使用版本。

匹配采用精确优先、逐级安全回退：

```text
业态+品类+人设+内容类型+商业强度
-> 业态+品类+内容类型+商业强度
-> 业态+内容类型+商业强度
-> 业态+内容类型
-> 通用餐饮+内容类型
-> 通用餐饮
```

平台必须记录实际模板版本、匹配层级和回退路径。平台、商业强度和安全规则不能被回退放宽；模板可以声明是否允许品类、业态或通用层级回退。

后台角色分离：平台运营编辑只能编辑/提交规则草稿，平台审核人员负责发布/退回/停用；服务商角色不能访问模板管理路由。

## Generation Workflow

```text
门店画像+经营阶段+客户灵感/数据+模板+生成选项
-> 生成 3 个动态题材方向
-> 客户选择一个方向
-> 生成 3 版原创文案
-> 客户选择一版并编辑
-> 保存草稿并审核
-> 客户确认文案
-> 基于确认文案生成逐镜头拍摄清单
-> 客户确认分镜
-> 内容任务进入待拍摄
```

三个题材方向必须有实质差异，优先覆盖真实故事/情绪共鸣、幕后过程/专业知识、生活场景/商品自然带出；具体角度根据业态和灵感动态变化。无法生成三个有意义方向时返回较少但高质量的方向，不使用同义标题凑数。换一批创建新生成批次，不覆盖旧批次。

文案一次生成三版，三版必须采用不同表达策略。客户选择一版后可以修改；未确认前可保存草稿，但不能生成分镜。客户确认后文案版本锁定，重新生成或换供应商都创建新版本。

## Model Provider Abstraction

业务 API 通过可插拔 `ModelProvider` 接口调用模型。第一期实现 DeepSeek 和通义千问适配器，服务端环境配置默认供应商；客户 App 不选择供应商。失败时只在同一供应商内有限重试，不静默切换。

每次生成保存实际 provider、model、promptVersion、templateVersion、输入必要字段快照、输出版本、用量、耗时和失败类别。Android 不接触模型密钥。模型输出必须经过结构校验、商业强度校验和风险检查。

## Review And Safety

审核采用确定性规则检查 + AI 辅助检查。平台审核规则库由运营编辑维护、审核人员发布，只有已发布规则生效。规则支持绝对化词、虚假销量/排名、功效/医疗暗示、价格优惠承诺、平台敏感表达、商业强度冲突和未确认事实引用等类型，并可设置禁止、高风险、警告和提示级别。

客户修改后的文案允许保存为草稿，但只有确定性禁止/高风险命中为零、AI 必须修改风险为零、商业强度冲突为零且审核服务成功，才能确认并生成分镜。风险文案停留在客户侧，不提交服务商。

规则发布不会自动重审客户草稿。平台审核人员可以选择草稿批量重审，每次重审保存规则版本、发起人、原因和新结果；不改写原文、不删除旧审核记录。已确认文案不会被规则发布自动回退。

## Douyin Feedback Import

第一期通过客户从抖音后台导出的 CSV/XLSX 报表回流，不做账号授权或自动同步。一次只选择一个已发布内容任务并导入一个单任务报表；多视频报表提示客户导出单视频数据，不自动猜测关联。

内容任务保存内部 ID、抖音视频链接、发布时间和任务配置。回流保存统计范围，支持发布后 3/7/14 天周期；日常内容默认 7 天，限时活动可选 3 天，复购/品牌认知等长期内容可选 14 天。周期结束前为观察中，周期完成后生成不可覆盖的效果快照。

报表字段由后台版本化维护映射模板。解析结果区分已识别、未提供和无法识别，不把缺失指标当成零。指标分为曝光播放、留存观看、互动和商业转化四组。

## Effect Review And Baseline

效果页按三段展示：内容表现、商品转化、经营目标。先显示事实和数据完整度，再显示可能原因和一条低复杂度实验建议，不把播放高等同于卖货成功。

数据完整度按内容目标判断：推广内容需要商品点击/领券/下单/核销等对应指标，品牌内容重点看播放/完播/互动。缺少核心指标只能做局部判断。

基线优先使用本店近 90 天同类内容，再逐级回退到本店同业态、同品类聚合和同业态聚合。样本少于 3 条不做可靠比较，3-5 条只看趋势，至少 6 条做基础比较，至少 10 条才建议进入训练候选。基线版本、范围和样本数必须保存。

效果结论分为已知事实、可能原因和建议验证。系统最多展示一条低复杂度实验建议，客户确认后才创建实验；实验只改变一个变量，同时保存假设、保持不变项、改变项和观察指标。

## Visibility And Training

未确认草稿、客户修改过程和审核风险只对客户本人可见。服务商可以查看其负责门店的确认最终文案、任务配置、视频链接和聚合效果指标，但不能查看原始报表或其他门店内容。

授权的平台 AI 训练/效果分析人员可以在平台内查看确认后的完整原文，但禁止批量导出或下载。确认内容先生成结构化训练样本候选，经自动质量检查和授权人员平台内审核后才进入训练集。训练集版本不可变；排除或撤回必须创建新版本并保留审计记录。

## Verification

第一期验收必须覆盖：首次建店必填画像和业态化模板匹配、目标阶段快照、三题材方向差异、三版文案选择与版本、客户侧规则/AI 审核拦截、DeepSeek/Qwen 适配器统一接口、单任务抖音报表导入与字段映射、3/7/14 天周期、目标分层数据完整度、90 天本店基线、实验建议确认、服务商可见性和平台训练样本审核审计。

本期不验收视频素材上传、自动剪辑、字幕/转场、渲染队列、自动发布或第三方平台自动同步。
