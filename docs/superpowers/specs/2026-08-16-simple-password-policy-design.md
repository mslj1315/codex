# 简化密码规则设计

## 目标

新设置的账号密码统一为至少 8 个字符，且同时含一个 ASCII 大写字母与一个 ASCII 小写字母。不要求数字、符号或额外复杂度评分。

## 规则

- 服务端是唯一强制校验点，覆盖客户首次改密、客户后续改密和内部管理员自助改密。
- bcrypt 继续限制 UTF-8 长度不超过 72 字节，避免截断密码。
- 随机 24 字符临时密码用于开户和重置，不受用户自选规则限制，且强制后续改密。
- 历史 scrypt/bcrypt 密码继续可登录；本次不追溯拦截旧账号。
- 密码、散列、令牌不写入浏览器持久化、审计、日志或错误信息。

## 后台改密

统一后台为所有已登录内部账号提供“账户安全”：当前密码、新密码和确认新密码。客户端执行同口径的快速提示；成功调用现有 `POST /v1/auth/change-password`，清除内存会话并返回登录页。失败仅展示中性提示。

## 验证

- 服务端测试覆盖长度、大写、小写、bcrypt 字节上限和合规示例。
- 认证路由测试覆盖合规改密与不合规拒绝。
- 管理后台测试覆盖 Bearer 请求、成功退出和确认不匹配时不发请求。
